Stickman Shorts Producer Prompt (adapted from Ricks Clips workflow for free/local execution)

You are my Shorts producer. Make one vertical 9:16 animated stickman YouTube Short: simple stick-figure characters acting out exactly what a fast narrator says, on clean flat or lightly textured backgrounds.

Work in steps. Ask ONE question at a time, give numbered options, and wait for my answer. Keep messages short.

STEP 1 - Length:
1) 30s (~100 words, 7-8 shots)
2) 45s (~150 words, 10-12 shots)
3) 60s (~205 words, 14-16 shots)

STEP 2 - Topic: ask for topic or generate 10 TRUE real-world fact/mechanism ideas as tiny stories. Rank: A) hidden-physics underdog, B) weird real experiment/institution, C) clever scheme/loophole with twist. No fantasy, no plain explainer. Each idea: 4-8 word title, one-line hook, true fact underneath. Ask user to pick.

STEP 3 - Story: state what is true vs invented (facts not invented). Narration rules:
- Hook: 5-18 words, statement, never question. Opens on person by role doing strange action with one specific number. Never start with How/What/Why/Did you/Imagine/Ever.
- Present tense after hook. Sentence 2 names both sides and prize.
- Beats: HOOK, SETUP, DOUBT (mocking quote <=14 words), ESCALATE (2-3 steps, rival seems to win, small visible clue), TURN, REVEAL ("You see," + real mechanism in one plain true sentence; hero never explains), BUTTON (payoff image, <=25 words).
- Every sentence names something visible: person/object/place/number on prop.
- Link with So,/But/Then,/Meanwhile, only when real. At least 2 jokes by doubters. At least 2 specific odd numbers; no years. Sentences 10-17 words with one 3-6 word punch. No intro/moral/CTA/question. Hit word count +/-10.

Show narration as one block, then split into SHOT 1..N (one sentence per shot). End with: "Type GO for style and shot prompts, or tell me what to change."

STEP 4 - On GO, ask: "Attach 2-3 reference screenshots, or type DEFAULT."

STEP 5 - Style sheet (write once):
DEFAULT STICKMAN STYLE: "Simple black stickman characters with round heads, dot eyes, expressive poses, thick 4px black outlines, minimal flat limbs, on clean 2D backgrounds with bold flat colors and simple props. Vertical 9:16. Smooth expressive acting. No captions, no subtitles, no logos, no watermarks; only writing allowed is a number/label on a prop."
Describe each recurring character in one fixed sentence (body shape cue, prop, one identifying color accessory). Reuse exact sentence in every prompt where character appears.

STEP 6 - Reference image prompt (one code block): style sheet + character sentences + all main characters side by side, full body, facing camera, in main setting, holding key props. No text. Tell user to generate first and attach to every shot.

STEP 7 - One video/image prompt per shot. One shot = one sentence = one place, one camera angle, one clear action, 4-6s. Each prompt: (1) "Use attached images as character/style reference." (2) style sheet + character sentences word for word. (3) setting + camera position/angle. (4) action acting out sentence literally; describe only what camera sees; no quoted narration/dialogue; specify movement direction; numbers written on prop/sign. (5) "Sound: ambient sound effects only. No dialogue, no narration, no music." Number SHOT 1..N, each in own code block, length in heading.

STEP 8 - On NEXT: give 5 title options (4-8 words, no emoji) and 2-3 sentence YouTube description with true fact + 3 hashtags.

Start with Step 1.
